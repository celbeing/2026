동물친구들 해설

등장 시간을 기다리고, 관람 순서를 선택하고, 출입구로 돌아오기.

N ≤ 15플로이드–워셜비트마스크 DP이분 탐색

01문제 다시 보기

0초에 출입구에서 출발하여 K초 이내에 돌아오면서 서로 다른 동물을 최대한 많이 봅니다. 우리를 방문한 것과 동물을 본 것은 다릅니다. 도착했을 때 동물이 없다면 기다리거나 나중에 다시 와야 합니다.

등장 구간의 양 끝은 포함합니다. 관람 시간은 0초이고, 같은 동물을 여러 번 보아도 한 마리입니다.

예제 2는 먼저 1번 우리를 지나 2번 동물을 보고, 돌아오는 길에 1번 동물을 보아야 두 마리를 모두 볼 수 있습니다. 가장 가까운 동물부터 기다리며 보는 탐욕법은 실패합니다.

02이동 경로와 관람 순서를 분리하기

어떤 동물을 다음에 볼지 정했다면, 그 우리까지 빨리 도착하는 것이 유리합니다. 일찍 도착하면 기다릴 수 있기 때문입니다. 따라서 모든 장소 쌍의 최단 이동 시간을 먼저 계산합니다.

dist[u][v] = min(dist[u][v], dist[u][via] + dist[via][v])

출입구까지 포함한 N+1개 장소에 플로이드–워셜을 적용합니다. 같은 두 장소를 잇는 여러 길은 가장 짧은 길로 초기화합니다. via 반복문은 가장 바깥에 둡니다.

최단 경로가 다른 우리를 거쳐도 괜찮습니다. 도중에 추가로 동물을 보게 되면 이득입니다. DP의 집합은 반드시 관람을 보장할 동물들을 기록하며, 실제로 본 동물 전체와 정확히 같아야 하는 것은 아닙니다.

03도착 후 가장 빨리 볼 수 있는 시각

우리별 등장 구간을 시작 시각순으로 정렬하고 겹치거나 끝점에서 만나는 구간을 합칩니다. 그러면 구간의 시작과 끝이 각각 증가합니다.

도착 시각을 x라고 합시다. 끝 시각이 x 이상인 첫 구간 [a, b]를 이분 탐색으로 찾습니다. 그 구간이 없다면 이번에는 볼 수 없습니다. 있다면 관람 시각은 max(x, a)입니다.

끝 시각과 정확히 같은 때 도착해도 볼 수 있으므로 bisect_left(ends, x)를 사용합니다.

예를 들어 [2, 4], [7, 9]에 등장한다면 4초 도착은 4초 관람, 5초 도착은 7초 관람, 10초 도착은 관람 불가입니다.

04집합을 비트마스크로 나타내기

동물이 최대 15마리이므로 관람할 동물 집합을 정수 하나로 표현할 수 있습니다. i번 동물은 1 << (i - 1)에 대응합니다.

dp[mask][i] = mask의 동물들을 관람하고,
              마지막으로 선택한 동물 i를 본 가장 이른 시각

동일한 집합을 보고 같은 우리에 있다면 더 이른 상태만 남깁니다. 이른 상태에서는 기다려서 늦은 상태의 모든 행동을 그대로 따라 할 수 있습니다. 따라서 도착 시각별로 별도의 DP를 만들 필요가 없습니다.

구현에서는 0번부터 시작하는 동물 인덱스와 일차원 배열을 사용합니다. dp[mask * N + i]가 위 상태에 대응합니다. 아직 아무 동물도 보지 않은 상태에서 출입구로부터 각 첫 동물까지 이동해 초기값을 만듭니다.

05다음 동물 선택과 퇴장 가능성

arrival = dp[mask][i] + dist[i][j]
seen = j번 동물을 arrival 이후 가장 빨리 볼 수 있는 시각
next_mask = mask | (1 << (j - 1))

j가 아직 집합에 없고 관람이 가능하면 다음 상태를 갱신합니다. 다만 seen + dist[j][0] > K이면 버립니다. 지금 최단 경로로 돌아가도 늦는 상태는 다른 우리를 더 방문해도 제시간에 돌아올 수 없습니다.

따라서 저장된 모든 상태는 퇴장 가능한 상태입니다. 그중 비트 수가 가장 많은 집합이 답이며, 아무 동물도 볼 수 없으면 0입니다. 이미 본 우리를 다시 지나가는 것은 최단 경로에 포함될 수 있으므로, 동물을 집합에 한 번만 추가하는 것과 충돌하지 않습니다.

06왜 최적의 답을 놓치지 않을까?

실현 가능성. 초기 상태와 모든 전이는 실제 최단 경로 이동과 기다리기로 실행할 수 있습니다. 각 상태에 기록된 동물은 모두 볼 수 있고, 퇴장 조건도 확인합니다. 중간에 추가로 본 동물이 있어도 기록된 동물 수가 불가능한 값이 되지는 않습니다.

최적 경로의 보존. 최적 관람 경로에서 동물들을 처음 본 순서대로 나열합니다. 이 순서를 DP에서 따라가면, 실제 이동보다 길지 않은 최단 이동과 가장 이른 관람 시각을 선택하므로 각 동물을 원래 경로보다 늦지 않게 볼 수 있습니다. 더 일찍 도착하면 기다릴 수 있어 이후 관람도 방해하지 않습니다. 최적 경로가 퇴장 가능한 만큼 이 상태들도 퇴장 가능성 검사에서 제거되지 않습니다.

따라서 DP는 최적 경로가 본 동물 수 이상을 달성하며, 기록한 수는 언제나 실제로 달성할 수 있습니다. 두 성질로부터 답이 최적임을 알 수 있습니다.

07시간과 공간 복잡도

과정시간
길 입력 및 최단 거리O(L + N³)
등장 구간 정렬·병합O(M log(M+1))
관람 집합 DPO(2ᴺ N² log(M+2))

공간은 O(2ᴺ N + N² + M)입니다. N=15일 때 일차원 DP 배열의 칸 수는 491,520개입니다. K초를 하나씩 순회하지 않으므로 K가 10억이어도 처리할 수 있습니다.

각 상태에서 마지막 위치와 다음 동물을 선택해야 하므로, 단순히 O(2ᴺ)이라고 계산하면 안 됩니다. 시간 창을 모두 선형 탐색하는 대신 병합 후 이분 탐색을 사용합니다.

08Python 정답 코드

아래 코드는 함께 제공한 solution.py와 같습니다.

import sys
from bisect import bisect_left


def solve():
    input = sys.stdin.buffer.readline
    n, l, m, k = map(int, input().split())
    inf = 10**30
    dist = [[inf] * (n + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        dist[i][i] = 0
    for _ in range(l):
        u, v, t = map(int, input().split())
        if t < dist[u][v]:
            dist[u][v] = dist[v][u] = t
    for via in range(n + 1):
        row = dist[via]
        for u in range(n + 1):
            base = dist[u][via]
            for v in range(n + 1):
                candidate = base + row[v]
                if candidate < dist[u][v]:
                    dist[u][v] = candidate

    windows = [[] for _ in range(n)]
    for _ in range(m):
        i, a, b = map(int, input().split())
        windows[i - 1].append((a, b))
    starts, ends = [], []
    for intervals in windows:
        merged = []
        for a, b in sorted(intervals):
            if merged and a <= merged[-1][1]:
                merged[-1][1] = max(merged[-1][1], b)
            else:
                merged.append([a, b])
        starts.append([a for a, _ in merged])
        ends.append([b for _, b in merged])

    # dp[mask * n + i]: earliest time after observing the selected
    # animals, with i being the last selected animal.
    # Incidental sightings on a route need not be recorded in this state.
    full = (1 << n) - 1
    unreachable = k + 1
    dp = [unreachable] * ((1 << n) * n)
    home = [dist[i + 1][0] for i in range(n)]
    for j in range(n):
        p = bisect_left(ends[j], dist[0][j + 1])
        if p < len(ends[j]):
            seen = max(dist[0][j + 1], starts[j][p])
            if seen + home[j] <= k:
                dp[(1 << j) * n + j] = seen

    answer = 0
    for mask in range(1, full + 1):
        offset = mask * n
        remaining = full ^ mask
        selected = mask
        while selected:
            bit = selected & -selected
            selected -= bit
            i = bit.bit_length() - 1
            current = dp[offset + i]
            if current == unreachable:
                continue
            answer = max(answer, mask.bit_count())
            if answer == n:
                print(n)
                return
            todo = remaining
            row = dist[i + 1]
            while todo:
                next_bit = todo & -todo
                todo -= next_bit
                j = next_bit.bit_length() - 1
                arrival = current + row[j + 1]
                if arrival + home[j] > k:
                    continue
                p = bisect_left(ends[j], arrival)
                if p == len(ends[j]):
                    continue
                seen = max(arrival, starts[j][p])
                if seen + home[j] <= k:
                    index = (mask | next_bit) * n + j
                    if seen < dp[index]:
                        dp[index] = seen
    print(answer)


if __name__ == '__main__':
    solve()
