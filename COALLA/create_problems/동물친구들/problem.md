# 동물친구들

## 문제 설명

동물원에는 하나의 출입구와 N개의 우리가 있습니다. 출입구는 0번이고, 우리는 1번부터 N번까지 번호가 붙어 있습니다. 각 우리에는 서로 다른 동물 한 마리가 살고 있습니다.

동물원에는 두 장소를 잇는 L개의 양방향 길이 있습니다. 장소란 출입구 또는 우리를 뜻합니다. 길마다 이동하는 데 걸리는 시간이 정해져 있으며, 길을 여러 개 거치면 출입구를 포함한 어느 장소에서든 다른 모든 장소로 이동할 수 있습니다. 같은 두 장소를 잇는 길이 여러 개 있을 수도 있습니다.

동물들은 정해진 시간대에만 모습을 드러냅니다. 등장 시간대 `i a b`는 i번 우리의 동물을 개장 시각으로부터 a초 후부터 b초 후까지 볼 수 있다는 뜻입니다. a초와 b초도 포함합니다. 같은 동물에게 여러 등장 시간대가 주어질 수 있으며, 시간대가 겹칠 수도 있습니다. 등장 시간대가 주어지지 않은 동물은 볼 수 없습니다.

여러분은 개장 시각인 0초에 출입구에서 출발하여, K초 이내에 출입구로 돌아와야 합니다. 각 장소에서 원하는 만큼 기다리거나, 같은 장소와 길을 여러 번 방문해도 됩니다. 동물이 모습을 드러낸 시각에 해당 우리에 있으면 즉시 그 동물을 볼 수 있으며, 관람에 별도의 시간은 들지 않습니다. 길을 이동하는 도중에는 동물을 볼 수 없습니다. 다른 우리를 거쳐 이동할 때는 거쳐 가는 우리에서도 같은 규칙으로 동물을 볼 수 있습니다.

같은 동물을 여러 번 보더라도 한 마리로 셉니다. 출입구에는 동물이 없습니다. 정해진 시간 안에 동물원을 둘러보고 출입구로 돌아오면서 볼 수 있는 서로 다른 동물의 최대 수를 구해 주세요. 출입구에서 계속 기다리다가 관람을 마쳐도 됩니다.

## 입력 설명

첫째 줄에 우리의 수 N, 길의 수 L, 등장 시간대의 수 M, 퇴장 제한 시각 K가 공백으로 구분되어 주어집니다.

다음 L개의 줄에 길 정보 `u v t`가 주어집니다. u번 장소와 v번 장소를 양방향으로 직접 이동할 수 있고, 이동에 t초가 걸린다는 뜻입니다.

다음 M개의 줄에 등장 시간대 `i a b`가 주어집니다. 시간대는 순서 없이 주어질 수 있습니다.

### 입력값의 범위

- 모든 입력값은 정수입니다.
- 1 ≤ N ≤ 15
- N ≤ L ≤ 1,000
- 0 ≤ M ≤ 3,000
- 1 ≤ K ≤ 1,000,000,000
- 0 ≤ u, v ≤ N, u ≠ v
- 1 ≤ t ≤ 1,000,000,000
- 1 ≤ i ≤ N
- 0 ≤ a ≤ b ≤ K
- 출입구를 포함한 N+1개의 장소는 모두 연결되어 있습니다.
- 중복된 길과 중복되거나 겹치는 등장 시간대가 주어질 수 있습니다.

권장 채점 제한: 시간 5초, 메모리 256 MiB. 실제 채점 서버에서 최대 입력의 실행 시간을 측정한 뒤 확정합니다.

## 출력 설명

K초 이내에 출입구로 돌아오는 조건을 지키면서 볼 수 있는 서로 다른 동물의 최대 수를 한 줄에 출력합니다. 볼 수 있는 동물이 없다면 0을 출력합니다.

## 예제 1 입력

```text
3 4 3 12
0 1 2
1 2 2
2 3 2
3 0 3
1 3 4
2 5 6
3 7 8
```

## 예제 1 출력

```text
3
```

### 예제 1 설명

2초에 1번 우리에 도착하여 3초까지 기다린 뒤 첫 번째 동물을 봅니다. 5초에 2번 우리, 7초에 3번 우리에서 각각 동물을 보고, 10초에 출입구로 돌아올 수 있습니다.

## 예제 2 입력

```text
2 2 3 8
0 1 3
1 2 1
1 0 2
1 5 6
2 4 4
```

## 예제 2 출력

```text
2
```

### 예제 2 설명

3초에 1번 우리를 지나 4초에 2번 동물을 봅니다. 다시 1번 우리로 돌아와 5초에 동물을 본 뒤 8초에 출입구로 돌아옵니다. 1번 우리에서 먼저 5초까지 기다리면 2번 동물의 등장 시간을 놓칩니다.

## 예제 3 입력

```text
1 1 1 5
0 1 3
1 3 5
```

## 예제 3 출력

```text
0
```

### 예제 3 설명

3초에 동물을 볼 수는 있지만, 출입구로 돌아오면 6초가 되어 퇴장 제한 시각을 넘깁니다.
